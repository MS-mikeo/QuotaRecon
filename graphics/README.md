# graphics/

Put the README hero image / any screenshots here. The main README embeds
`graphics/quotarecon-banner.png` at the top of the page — drop your banner in
with that exact filename (or update the README to point to whatever you name
it).

Suggested images:

- `quotarecon-banner.png` — the top-of-page hero (used by README).
- `summary-sheet.png` — a screenshot of the `Summary` sheet with green/red
  conditional formatting; helps first-time visitors understand the output.
- `zonemap-sheet.png` — a screenshot of the `ZoneMap` sheet showing the
  logical → physical mapping.

Nothing here is required for the script to run; it's purely visual.
